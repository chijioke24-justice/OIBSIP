# Data Cleaning Project

## Objective
Transform a messy concert tour dataset into a clean and analysis-ready dataset by identifying and correcting data quality problems.

## Tools Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Tasks Performed
- Data quality inspection
- Missing value identification and handling
- Duplicate row checking and removal
- Column name standardisation
- Cleaning ranking values
- Cleaning monetary values
- Removing unwanted symbols and citation markers
- Outlier detection using the IQR method
- Data type correction
- Before and after cleaning comparison
- Exporting the cleaned dataset to CSV

## Dataset
The dataset contains information about major concert tours, including artist names, tour titles, rankings, gross revenue, number of shows, and average gross revenue.

## Output
A cleaned version of the original dataset was saved as a new CSV file.
