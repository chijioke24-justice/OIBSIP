# House Price Prediction Using Linear Regression

## Objective
Build and evaluate a Linear Regression model to predict house prices using property characteristics from the King County housing dataset.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Tasks Performed
- Exploratory Data Analysis
- Missing value and data type inspection
- House price distribution analysis
- Feature selection
- Date feature transformation
- Correlation analysis
- 80/20 train-test split
- Linear Regression model training
- Model evaluation using MSE, RMSE, and R²
- Actual vs predicted price visualisation
- Residual analysis
- Coefficient analysis
- Ridge Regression comparison

## Model Result
The Linear Regression model achieved an R² score of approximately 0.703, meaning that it explained about 70.3% of the variation in house prices.

The Linear Regression model performed slightly better than the Ridge Regression model.

## Dataset
The project uses the King County house sales dataset containing property features such as bedrooms, bathrooms, living area, grade, condition, waterfront status, location, and year built.
