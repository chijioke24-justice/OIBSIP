# Exploratory Data Analysis on Retail Sales Data

## Objective
Perform exploratory data analysis on a customer shopping dataset to identify sales trends, customer demographics, product category performance, and useful business insights.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Tasks Performed
- Dataset inspection and null value checks
- Descriptive statistics
- Monthly and quarterly sales analysis
- Customer age group analysis
- Gender distribution analysis
- Revenue analysis by product category
- Best-selling category analysis
- Correlation heatmap
- Additional gender and category spending analysis
- Business recommendations based on findings

## Dataset
The project uses a customer shopping dataset containing information such as customer age, gender, product category, quantity, price, payment method, shopping mall, and transaction date.
